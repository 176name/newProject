# 环境恢复与启动指南（2026-11-10 恢复版）

## 一、整体架构

```
Windows 笔记本
├── 前端 Vue3 (vite dev, 端口 5173)
├── 后端 Spring Boot (JDK 8, 端口 8081)
├── AI 引擎 Python FastAPI (端口 5001) — 陌生人检测 + 摔倒检测
├── MySQL 8.0 (Windows 服务 MySQL80, 端口 3306, 库 streaming_db)
└── FFmpeg 摄像头推流 (笔记本摄像头 → ZLM)

VMware CentOS 7 VM (IP: 192.168.6.145, NAT 网段 192.168.6.0/24)
└── Docker 容器
    ├── zlm       ZLMediaKit (9999=HTTP API, 554=RTSP, 1935=RTMP)
    ├── mysql     5.7 (本项目未使用，保留)
    └── nginx     8888 → 录像文件回放 (/home/itheima/video_record 挂载)
```

**视频链路（笔记本摄像头）：**
```
摄像头 → FFmpeg(RTSP推流) → ZLM(live/webcam) → 前端播放(HTTP-FLV)
                                  └→ 后端抓帧 → AI引擎(YOLOv8+人脸) → 告警
```

**数据流关键配置：** 设备表中 `rtsp_url` 字段支持三种模式：
- `push://live/webcam` — 外部推流模式（笔记本摄像头用，ZLM 自动注册流）
- `rtsp://...` — 自定义拉流地址（手机 IP 摄像头 App 用，ZLM 拉流代理）
- 空 — 传统海康格式（已废弃，摄像头已归还）

## 二、启动步骤（按顺序）

> 💡 **一键启动**：完成第 1、2 步（虚拟机 + MySQL）后，直接双击 `scripts\启动全部.bat`，
> 会自动打开 4 个窗口分别启动 后端/AI/前端/摄像头推流。以下为手动分步方式。

### 1. 启动虚拟机
1. 打开 VMware Workstation（D:\VM\vmware.exe）
2. 启动 "CentOS 7 64 位" 虚拟机（若显示"已挂起"选恢复）
3. 等 1-2 分钟，验证：浏览器打开 `http://192.168.6.145:9999/index/api/getThreadsLoad?secret=<ZLM_SECRET>` 应返回 JSON（secret 值见 backend 的 application.yml 中 `zlm.secret`）
4. VM 登录账号 itheima（密码为本人日常使用密码）；容器 zlm/mysql/nginx 已设开机自启，无需手动操作

### 2. 启动 MySQL（Windows）
管理员身份打开终端：
```
net start MySQL80
```
（root 密码见 backend 的 application.yml 中 `spring.datasource.password`）

### 3. 启动后端（JDK 8）
双击 `scripts\start_backend.bat`（或手动）：
```bat

"C:\Users\DWMDN\.jdks\corretto-1.8.0_482\bin\java.exe" -jar target\backend-1.0-SNAPSHOT.jar
```
验证：`http://localhost:8081` 有响应
> 注意：数据库密码/ZLM secret/千问 Key 都在 `application-dev.yml`（gitignore）中，通过 `spring.profiles.active: dev` 加载。若克隆代码到新机器需自行创建该文件。

### 4. 启动 AI 引擎
```bat

set PYTHONIOENCODING=utf-8

```
验证：`http://localhost:5001/health` 返回 ok

### 5. 启动前端
```bat

```
访问：`http://localhost:5173`，登录 admin / 123456

### 6. 启动摄像头推流
双击 `scripts\start_webcam.bat`（断线自动重连，关闭窗口即停止）
验证：监控大屏出现画面；`http://192.168.6.145:9999/index/api/getMediaList?secret=...` 能看到 live/webcam

## 三、常用排查

| 现象 | 处理 |
|------|------|
| VM 起不来 | 检查 VMware 中 VM 状态；若提示锁文件，删除 D:\Linux\ 下 *.lck 目录（VM 未运行时） |
| ZLM 9999 不通 | SSH 进 VM 后 `systemctl restart docker`（network restart 会冲掉 docker iptables） |
| 后端起不来 | 确认 MySQL80 已启动；确认用 JDK 8 运行（JDK 21 编译会报 Lombok 错误） |
| AI 报 UnicodeEncodeError | 必须加 `set PYTHONIOENCODING=utf-8` |
| 画面黑屏 | 确认 start_webcam.bat 在跑；确认 ZLM 里 live/webcam 流存在（getMediaList 接口） |
| 录像没有文件 | 已修复：ZLM 录制 API 必须用 type=1（MP4） |
| 录像回放 404 | 确认 VM 里 nginx 容器在运行（8888 端口） |
